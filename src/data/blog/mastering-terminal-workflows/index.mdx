## 二、Part 1：桌面端神器 Clash Verge Rev 深度实操配置

Clash Verge Rev 采用跨平台 Tauri 框架与现代 UI 设计，底层深度集成了持续维护的 Mihomo (Clash Meta) 内核，是目前 PC 与 Mac 平台毫无争议的首选。

```
常规配置流程图：
[下载安装] ──> [安装 Service Mode] ──> [导入订阅 URL] ──> [启用 TUN 模式] ──> [测试延迟并连接]
```

### 步骤 1：安装服务模式（Service Mode）

1. 启动 Clash Verge Rev，进入左侧导航栏的 **「设置 (Settings)」**。
2. 找到 **「服务模式 (Service Mode)」** 项，点击右侧的 **「安装 (Install)」**。
3. 弹出系统 UAC 授权窗口，点击允许。安装完成后服务模式图标将显示为绿色打勾状态。
   > **为什么必须装？**：服务模式为 TUN 虚拟网卡提供高权限底层支撑，避免每次重启软件都需要重新申请管理员权限。

### 步骤 2：导入机场订阅链接

1. 打开你的机场后台（例如登录 [光速云官方控制台](/airports/guangshuyun/)），找到“便捷导入”或“复制订阅地址”按钮。
2. 回到 Clash Verge Rev，点击左侧 **「订阅 (Profiles)」**。
3. 在顶部输入框粘贴订阅链接，点击 **「保存并下载 (Save & Import)」**。
4. 订阅下载完成后，点击选中该配置文件，使其右侧呈现高亮激活状态。
5. 建议右键该订阅，设置 **「自动更新时间间隔」** 为 `1440` 分钟（即每日自动同步一次节点与故障容灾列表）。

### 步骤 3：核心设置：开启 TUN 模式与规则分流

1. 点击左侧 **「代理 (Proxies)」**，在顶部选择 **「规则 (Rule)」** 模式（千万不要选“全局 (Global)”，否则连百度微信都会走代理消耗流量）。
2. 在策略组中，选择你想要连接的节点（建议选择“自动选择”或低延迟的香港/日本/新加坡 IEPL 节点）。
3. 返回 **「设置」** 界面，开启 **「TUN 模式 (TUN Mode)」** 开关。
4. 同时开启 **「开机自启」** 与 **「静默启动」**。

## 三、Part 2：移动端标配 Shadowrocket（小火箭）实战配置

Shadowrocket 是 iOS 平台上最为经典的代理客户端，轻巧省电且功能强大。

### 步骤 1：准备外区 Apple ID 并下载

由于众所周知的原因，小火箭在国区 App Store 处于下架状态。用户需登录外区（美区、日区、港区等）Apple ID，在 App Store 搜索购买正版安装（售价通常为 $2.99）。

### 步骤 2：一键订阅添加

1. 手机 Safari 浏览器登录机场后台，点击 **「一键导入 Shadowrocket」**，系统会自动拉起小火箭完成添加。
2. 若手动导入：打开小火箭，点击右上角 **「+」** 号，类型选择 **「Subscribe」**，在 URL 栏粘贴机场提供的订阅链接，备注填写如“光速云”，点击右上角完成。
3. 小火箭将自动拉取所有节点列表。

### 步骤 3：全局路由选择与开启

1. 首页找到 **「全局路由」** 选项，务必将其切换为 **「配置 (Config)」**。
2. 在节点列表中，轻触选中你心仪的节点（节点前方出现橙色圆点标记）。
3. 开启最顶部的连接开关，在弹出的 iOS 提示中允许添加 VPN 配置，验证 Face ID / Touch ID 即可成功联网。

## 四、DNS 泄漏与污染防范配置（高阶隐私安全）

在默认情况下，即便开启了代理，某些浏览器的 DNS 查询仍可能通过本地运营商宽带的 53 端口发出，从而将你访问的域名暴露给运营商。

### Clash Verge Rev 防 DNS 泄漏配置建议：

在客户端「订阅」右键 ->「扩展配置」或在全局配置中引入安全的加密 DNS：

```yaml
dns:
  enable: true
  listen: 0.0.0.0:1053
  ipv6: false
  enhanced-mode: fake-ip
  fake-ip-range: 198.18.0.1/16
  nameserver:
    - 223.5.5.5
    - 119.29.29.29
  fallback:
    - https://1.1.1.1/dns-query
    - https://8.8.8.8/dns-query
```

- `fake-ip` 模式可以在本地瞬间返回虚拟 IP，将真实 DNS 查询交给远程专线代理服务器执行，既彻底隔绝了运营商 DNS 污染，又大幅降低了网页首帧解析延迟。

## 五、新手常见报错秒级排查自救手册

在日常使用中，遇到网络故障请依照以下树状图快速自检：

| 故障现象                              | 根源排查点                           | 解决方案                                                                                             |
| :------------------------------------ | :----------------------------------- | :--------------------------------------------------------------------------------------------------- |
| **全部节点测试超时 (Timeout / -1ms)** | 本地系统时间与网络授时误差超过 60 秒 | 打开系统设置，关闭再开启“自动设置时间”，手动同步时间                                                 |
| **打开网页提示 ERR_CONNECTION_RESET** | 订阅已过期或流量已耗尽               | 登录机场后台查看套餐剩余流量与有效期                                                                 |
| **国内微信、网银变慢或无法打开**      | 误开了“全局 (Global)”模式            | 将代理模式切换回“规则 (Rule)”分流模式                                                                |
| **终端命令行 (Git/npm) 无法拉取**     | 命令行默认不走系统 HTTP 代理         | 在设置中开启 **TUN 虚拟网卡模式**，或手动配置 `http_proxy` 变量                                      |
| **ChatGPT 提示 Access Denied**        | 节点 IP 被 OpenAI 风控识别为机房 IDC | 切换到机场的“流媒体/AI 专属”原生住宅节点（详见 [AI 原生解锁原理](/blog/the-art-of-pixel-graphics/)） |

## 六、常见问题 FAQ（操作与维护答疑）

### Q1：为什么小火箭或 Clash 导入订阅提示“网络请求失败 / 解析错误”？

> **答**：通常有三个可能：1. 机场订阅链接被本地网络运营商劫持，尝试切换手机热点再点击更新；2. 订阅链接中包含特殊字符未转义，向机场客服获取短链接；3. 机场后端正在进行维护，稍后尝试。

### Q2：开启 TUN 模式对玩游戏有帮助吗？

> **答**：帮助非常大。常规系统代理只能接管使用 HTTP/SOCKS 协议的浏览器应用，绝大多数网络游戏（使用原生 UDP/TCP 通信）根本不会遵循系统代理设置。开启 TUN 模式后，系统在底层创建虚拟网络适配器，实现游戏流量 100% 捕获转发。

### Q3：同一套订阅可以在多台设备上同时使用吗？

> **答**：取决于你购买的机场套餐规则。例如在 [光速云](/airports/guangshuyun/) 中，标准套餐通常允许 3~5 台设备同时在线并发，完全能够覆盖个人的主力 PC、Mac、iPhone 和 iPad。严禁将订阅公开发布到网络论坛，否则触发风控将导致订阅被封禁。

### Q4：为什么每次更新订阅后，自定义规则就消失了？

> **答**：直接在下载的远程配置文件上修改规则，会在下一次更新订阅时被覆盖。正确的做法是利用 Clash Verge Rev 的 **「订阅扩展配置 (Script/Merge)」** 功能编写预处理脚本，实现自定义规则的持久化注入。

### Q5：如何确认当前翻墙是否真正走的是 IEPL 专线？

> **答**：可以通过第三方 IP 检测网站（如 `ipinfo.io` 或 `whoer.net`）检测当前出口 IP 的地理位置与 ASN 信息，同时观察 Ping 延迟。如果在晚高峰连接香港节点延迟稳定在 20ms~30ms 且波动极小，即为纯正专线特征。
