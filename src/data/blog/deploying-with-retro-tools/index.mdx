## ⚡ Answer Block：协议选型权威决策结论

不同网络拓扑环境下，没有所谓的“绝对无敌协议”，只有最适配当前场景的最优解：

1. **公网自建 / 抗主动探测场景**：首选 **VLESS-Reality**。无需自备域名，直接“借用”海外大型合规网站（如 Apple/Yahoo/Microsoft）的 TLS 证书与 SNI 指纹，彻底免疫 GFW 的主动探测与证书指纹分析。
2. **商业专线 / 极速低延迟场景**：如果你的机场走的是 [IEPL 纯内网物理专线](/blog/history-of-the-floppy-disk/)（如 <a href="https://sahude.gsyvipaff.com/#/?code=keqgvT5Y" target="_blank" rel="nofollow sponsored noopener">**光速云**</a>），首选 **Shadowsocks-2022** 或 **Trojan**。由于内网专线不经过 GFW，去除多余的二次加密与复杂握手后，握手延迟最低、移动端手机最省电。
3. **极度恶劣弱网 / 高丢包丢帧环境**：可备用基于 UDP 开发的 **Hysteria 2** 协议，通过暴力拥塞控制强行突破丢包限速。

## 一、主流代理协议技术演进路线图

从 2012 年第一代开源科学上网工具诞生至今，代理协议经历了四次技术脱胎换骨式的代际演进：

```
[第 1 代：Shadowsocks / SSR] ──> 特征：简单对称加密 (AES-256-GCM / Chacha20)
       │ (缺陷：被深度包检测机器学习与主动探测识破流量熵值分布)
       ▼
[第 2 代：VMess / V2Ray]     ──> 特征：复杂多重握手认证 + 动态时间戳
       │ (缺陷：握手 RTT 开销大、CPU 占用偏高、仍存在 TLS-in-TLS 特征)
       ▼
[第 3 代：Trojan-GFW]        ──> 特征：将流量完美伪装成合法标准 HTTPS/TLS (443 端口)
       │ (优势：高度成熟、全平台客户端兼容性最佳；缺陷：需要维护自签名或真实域名证书)
       ▼
[第 4 代：VLESS-Reality]     ──> 特征：剔除协议内置加密，借用大厂合规证书实现零指纹伪装
       │ (优势：抗探测能力天花板，省去域名维护成本)
```

## 三、各核心协议深度机制拆解

### 1. VLESS (with Reality & Vision)
- **去繁就简的设计哲学**：VLESS 移除了 VMess 臃肿的自身加密层，只负责身份鉴权（UUID）与流量路由。数据本身的安全性完全托付给外层的 TLS 协议。
- **Reality 终极伪装原理**：传统的 Trojan 需要站长自己购买域名并申请 Let's Encrypt 证书。而 Reality 允许服务端直接“借用”外部大型合法网站（如 `gateway.icloud.com` 或 `www.yahoo.com`）的公钥证书。当 GFW 进行主动握手探测时，服务端直接将请求透明转发给真实的大厂服务器，返回完全合规的握手响应，令审查系统无法区分该 IP 是代理还是正常 Web 服务。

### 2. Trojan-GFW
- **成熟稳健的标准 Web 伪装**：Trojan 放弃自定义加密报文结构，全面模仿最通用的 HTTPS 请求。如果客户端发送了错误的密码，Trojan 服务端会直接返回内置的 Nginx 静态网页，从而在逻辑上与正常的个人博客毫无二致。
- **广泛的客户端支持**：几乎全平台所有流行翻墙软件（包括小火箭、Surge、Clash Verge Rev、Loon、v2rayN）均内置原生支持，稳定度极高。

### 3. Shadowsocks-2022 (新一代 SS 标准)
- 为解决老旧 Shadowsocks 容易受到重放攻击和主动探测识别的缺陷，社区发布了全新的 SS-2022 规范。
- 采用全新的固定长度头部加密与会话子密钥派生机制，大幅减少了特征指纹。在优质内网专线（如 [光速云 IEPL 专线](/airports/guangshuyun/)）配合下，SS-2022 展现出了无与伦比的高并发吞吐量与极低系统开销。

## 六、常见问题 FAQ（协议技术高频疑问）

### Q1：为什么有些客户端配置 VLESS-Reality 提示无法解析或报错？
> **答**：因为 Reality 属于较新的特性，老版本的 Clash 原版内核（已停更）无法识别该配置语法。必须升级到使用 **Mihomo (Clash Meta) 内核** 的现代化客户端（如 Clash Verge Rev 1.7+ 或 Sing-box）。请前往 [客户端下载中心](/clients/) 更新至最新版本。

### Q2：VLESS-Reality 会窃取被借用域名的账号信息吗？
> **答**：完全不会。Reality 只是在 TLS 握手阶段利用了被借用域名的公钥证书作为伪装掩护，双方实际通信的数据密钥仍然是由客户端与你的代理服务端协商生成的对称密钥，没有任何中间人可以解密。

### Q3：纯 Trojan 协议为什么现在很多机场还在大量使用？
> **答**：因为 Trojan 具有极致的成熟度与生态兼容性。从 iPhone 上的老旧软件到各种软路由、嵌入式硬件网关，Trojan 都能即插即用，且伪装成标准 443 端口 HTTPS 流量在绝大多数企业办公网络和校园网中都不容易被拦截。

### Q4：为什么我使用 UDP 协议（如 Hysteria 2）在公司或校园网完全连不上？
> **答**：很多企业局域网、高校校园网或公共 Wi-Fi 的路由器会对 UDP 流量进行严格的速率限制甚至直接阻断非 53 端口的 UDP 出境。在这种网络环境下，基于标准 TCP/TLS 的 **Trojan** 或 **VLESS** 才是最稳妥的选择。

### Q5：专线机场和协议之间是什么关系？
> **答**：专线是“路”（底层物理传输通道），协议是“车”（数据打包与封装规则）。即便是开着一辆普通的车（Trojan/SS），如果跑在没有行人的高速封闭专线（IEPL）上，速度依然极快；反之，哪怕开着最先进的跑车（Reality），如果堵在公网羊肠小道上（晚高峰 163 骨干网），依然会严重丢包。因此，选择像 [光速云](/airports/guangshuyun/) 这样具备优质专线路网的服务商才是根本。
